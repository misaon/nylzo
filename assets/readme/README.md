# README cover

`cover-light.svg` and `cover-dark.svg` use the official Nylzo logo geometry and theme colors from [the brand kit](../brand). The sealed-message artwork illustrates encrypted sharing and expiry; it is not a product screenshot or a security certification.

The covers are static, self-contained SVG files with opaque artwork and accessible descriptions. They use no scripts, animation, embedded HTML, remote assets, or custom font downloads. Keep the light/dark compositions aligned when editing them.
