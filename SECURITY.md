# Security policy

Report vulnerabilities [privately through GitHub Security Advisories](https://github.com/misaon/nylzo/security/advisories/new). Include the affected version or source commit, reproduction steps using synthetic data, and the attacker's capabilities. Keep real message links, passphrases, credentials, and other people's data out of reports.

Only the latest stable release receives security fixes. Older versions and prerelease builds are not maintained. The maintainer aims to acknowledge reports within five business days; this is a best-effort target. If there is no acknowledgement, add a comment to your private report.

The Wiki contains the full [disclosure policy](https://github.com/misaon/nylzo/wiki/Security-policy), [security model](https://github.com/misaon/nylzo/wiki/Security-model), and [release verification instructions](https://github.com/misaon/nylzo/wiki/Verify-a-release).

For abusive content on an instance, write to the operator contact on that instance's `/transparency` page, if it lists one.
