# Contributing to Nylzo

Bug reports, documentation, accessibility work, and code are welcome. Read the [contributing guide in the Wiki](https://github.com/misaon/nylzo/wiki/Contributing) for setup, tests, and the pull-request process.

Use English and synthetic data in issues and pull requests. Discuss changes to cryptography, the protocol, storage, or releases before implementing them. Follow the [code of conduct](CODE_OF_CONDUCT.md).

- [Report a bug or propose a feature](https://github.com/misaon/nylzo/issues/new/choose).
- [Ask a question](https://github.com/misaon/nylzo/discussions).
- [Report a vulnerability privately](https://github.com/misaon/nylzo/security/advisories/new), following [SECURITY.md](SECURITY.md).

Contributions are distributed under the [MIT license](LICENSE). Submit only work you have the right to contribute.
